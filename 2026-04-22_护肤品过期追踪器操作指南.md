### 3.2 核心差异化：PAO图标拍照识别

**这是我们的杀手级功能，所有竞品均无此功能。**

PAO(Period After Opening)图标是印在护肤品包装上的"开封罐"标志，如"12M"表示开封后12个月内使用。但：
- 图标极小(通常<5mm)，难以辨认
- 70%用户不知道其含义
- 不同产品PAO期限不同(3M/6M/12M/24M)
- 手动查找和输入太麻烦

**SpoilAlert的解决方案**：用户对准PAO图标拍照 → Vision OCR自动识别"12M"等文字 → 自动计算过期日期 → 完成！

### 5.2 PAO图标识别服务 (Vision OCR)

```swift
import Vision
import UIKit

/// PAO图标识别服务
/// 识别护肤品瓶身上的"开封罐"图标文字，如"12M"、"6M"、"24M"
final class PAORecognitionService {
    
    /// 识别结果
    struct PAOResult {
        let paoMonths: Int
        let confidence: Float
        let recognizedText: String
    }
    
    /// 从图片识别PAO期限
    /// - Parameter image: 拍摄的产品图片
    /// - Returns: PAO识别结果
    static func recognizePAO(from image: UIImage) async throws -> PAOResult? {
        guard let cgImage = image.cgImage else {
            throw PAOError.invalidImage
        }
        
        // Step 1: 使用Vision进行文字识别
        let textObservations = try await performOCR(on: cgImage)
        
        // Step 2: 从识别文字中提取PAO信息
        return extractPAO(from: textObservations)
    }
    
    // MARK: - OCR识别
    
    private static func performOCR(on cgImage: CGImage) async throws -> [VNRecognizedTextObservation] {
        try await withCheckedThrowingContinuation { continuation in
            let request = VNRecognizeTextRequest { request, error in
                if let error = error {
                    continuation.resume(throwing: error)
                    return
                }
                let observations = request.results as? [VNRecognizedTextObservation] ?? []
                continuation.resume(returning: observations)
            }
            
            // 配置OCR参数
            request.recognitionLevel = .accurate       // 高精度模式
            request.recognitionLanguages = ["en-US"]   // 英语
            request.usesLanguageCorrection = true       // 启用语言纠正
            request.minimumTextHeight = 0.01           // 识别小文字
            
            let handler = VNImageRequestHandler(cgImage: cgImage, options: [:])
            
            DispatchQueue.global(qos: .userInitiated).async {
                do {
                    try handler.perform([request])
                } catch {
                    continuation.resume(throwing: error)
                }
            }
        }
    }
    
    // MARK: - PAO提取
    
    /// 从OCR结果中提取PAO月数
    /// 支持格式: "12M", "12 M", "12m", "12 m", "12个月", "12M PAO"
    private static func extractPAO(from observations: [VNRecognizedTextObservation]) -> PAOResult? {
        let patterns = [
            // 标准PAO格式: 数字+M
            try? NSRegularExpression(pattern: "(\\d{1,2})\\s*[Mm]\\b"),
            // 带PAO前缀
            try? NSRegularExpression(pattern: "PAO\\s*(\\d{1,2})\\s*[Mm]"),
            // "X months"格式
            try? NSRegularExpression(pattern: "(\\d{1,2})\\s*month"),
            // 中文格式
            try? NSRegularExpression(pattern: "(\\d{1,2})个?月")
        ].compactMap { $0 }
        
        var bestResult: PAOResult?
        var bestConfidence: Float = 0
        
        for observation in observations {
            guard let candidate = observation.topCandidates(1).first else { continue }
            let text = candidate.string
            let confidence = candidate.confidence
            
            for pattern in patterns {
                let range = NSRange(text.startIndex..., in: text)
                if let match = pattern.firstMatch(in: text, range: range),
                   let monthRange = Range(match.range(at: 1), in: text),
                   let months = Int(text[monthRange]),
                   months > 0 && months <= 36 {
                    
                    if confidence > bestConfidence {
                        bestConfidence = confidence
                        bestResult = PAOResult(
                            paoMonths: months,
                            confidence: confidence,
                            recognizedText: text
                        )
                    }
                }
            }
        }
        
        return bestResult
    }
    
    enum PAOError: LocalizedError {
        case invalidImage
        case noPAOFound
        
        var errorDescription: String? {
            switch self {
            case .invalidImage: return "Invalid image provided"
            case .noPAOFound: return "No PAO information found in image. Try taking a closer photo of the jar symbol."
            }
        }
    }
}
```

|------|------|
| **架构模式** | MVVM (Model-View-ViewModel)，Model使用SwiftData @Model宏 |
| **UI框架** | 纯SwiftUI，不使用UIKit（除非必须的AVFoundation相机） |

| **最低部署** | iOS 17.0（SwiftData稳定版要求） |
| **无第三方依赖** | 不使用CocoaPods/SPM第三方库，全部使用Apple原生框架 |

## 9. 价格策略深度设计

### 9.1 定价哲学

**核心原则**: 免费版让用户产生依赖 → 3个产品限制触发升级需求 → 多层定价匹配不同付费意愿

**定价心理学依据**:
- 美国女性年均护肤品消费$200+，$2.99/月占1.5%，感知成本极低
- 过期护肤品导致的皮肤问题医疗费用$100-500/次，$2.99/月是极低保险
- 年付折扣>80%创造强烈"划算"感知，推动年付选择（降低流失率）

### 9.3 定价详细分析

#### 月度 vs 年度定价逻辑

#### 终身买断定价逻辑

| 因素 | 分析 |
|------|------|
| Pro年费$34.99 | 终身$49.99 = 1.43年回本 |
| 用户平均使用时长 | 护肤品追踪类App 2-3年 |
| 心理锚点 | $49.99 < $34.99×2，"不到2年就回本" |
| 竞品对比 | CosmeTick $34.99(不确定是否终身) |
| 目标转化 | 长期用户(>1年)选择终身，短期用户选月付 |

#### 免费版限制策略(关键转化钩子)

**3个产品限制的心理学设计**:

1. **触发时机**: 用户添加第4个产品时弹出升级提示
2. **文案设计**: "You've filled your free slots! Most women use 12+ products. Unlock unlimited tracking for just $2.99/month."
3. **数据展示**: "Average SpoilAlert user tracks 8 products and saves $200/year by avoiding expired skincare."
4. **社交证明**: "Join 50,000+ women who never use expired skincare"

**为什么3个而不是5个?**
- 3个产品勉强覆盖洁面+面霜+防晒(最基础)
- 用户几乎一定有>3个产品(爽肤水、精华、眼霜...)
- 3个限制制造"不完整感"，强烈驱动升级

### 9.5 StoreKit 2 订阅代码框架

```swift
import StoreKit

/// 订阅管理器
@MainActor
final class SubscriptionManager: ObservableObject {
    
    @Published var products: [Product] = []
    @Published var purchasedProductIDs: Set<String> = []
    @Published var subscriptionGroupStatus: Product.SubscriptionInfo.Status?
    
    // 产品ID
    static let plusMonthlyID = "com.spoilalert.plus.monthly"
    static let plusYearlyID = "com.spoilalert.plus.yearly"
    static let proMonthlyID = "com.spoilalert.pro.monthly"
    static let proYearlyID = "com.spoilalert.pro.yearly"
    static let lifetimeID = "com.spoilalert.lifetime"
    
    var currentTier: SubscriptionTier {
        if purchasedProductIDs.contains(Self.proMonthlyID) ||
           purchasedProductIDs.contains(Self.proYearlyID) {
            return .pro
        } else if purchasedProductIDs.contains(Self.plusMonthlyID) ||
                  purchasedProductIDs.contains(Self.plusYearlyID) {
            return .plus
        } else if purchasedProductIDs.contains(Self.lifetimeID) {
            return .pro // 终身=Pro
        }
        return .free
    }
    
    /// 加载产品信息
    func loadProducts() async {
        do {
            let storeProducts = try await Product.products(for: [
                Self.plusMonthlyID, Self.plusYearlyID,
                Self.proMonthlyID, Self.proYearlyID,
                Self.lifetimeID
            ])
            products = storeProducts.sorted { $0.price < $1.price }
        } catch {
            print("Failed to load products: \(error)")
        }
    }
    
    /// 购买产品
    func purchase(_ product: Product) async throws -> StoreKit.Transaction? {
        let result = try await product.purchase()
        
        switch result {
        case .success(let verification):
            let transaction = try checkVerified(verification)
            purchasedProductIDs.insert(product.id)
            await transaction.finish()
            return transaction
            
        case .userCancelled, .pending:
            return nil
            
        @unknown default:
            return nil
        }
    }
    
    /// 恢复购买
    func restorePurchases() async {
        do {
            try await AppStore.sync()
        } catch {
            print("Failed to restore purchases: \(error)")
        }
    }
    
    /// 验证交易
    private func checkVerified<T>(_ result: VerificationResult<T>) throws -> T {
        switch result {
        case .unverified(_, let error):
            throw error
        case .verified(let safe):
            return safe
        }
    }
}

enum SubscriptionTier: String, CaseIterable {
    case free
    case plus
    case pro
    
    var maxProducts: Int {
        switch self {
        case .free: return 3
        case .plus, .pro: return .max
        }
    }
    
    var hasPAORecognition: Bool { self != .free }
    var hasBarcodeScanner: Bool { self != .free }
    var hasMultiReminder: Bool { self != .free }
    var hasSkinLog: Bool { self != .free }
    var hasICloudSync: Bool { self == .pro }
    var hasFamilySharing: Bool { self == .pro }
    var hasDataExport: Bool { self == .pro }
}
```

### 10.6 动画与交互规范

| 交互 | 动画 | 时长 | 曲线 |

| 过期提醒 | 顶部横幅滑入+震动 | 0.5s | spring |

### 11.5 关键风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| PAO识别准确率低 | 用户体验差 | 提供手动选择PAO作为后备；持续优化OCR模型 |
| 免费版3产品转化率低 | 收入不及预期 | A/B测试限制(3/5/7个)；优化升级提示文案 |
| Apple审核被拒 | 上架延迟 | 确保隐私政策完整；无隐藏功能；IAP合规 |
| 竞品跟进PAO功能 | 差异化丧失 | 快速迭代，6个月内建立用户壁垒(数据+习惯) |
| 护肤品数据库不够全 | 条码查询失败 | 初期依赖手动输入+PAO识别；后期社区贡献 |
